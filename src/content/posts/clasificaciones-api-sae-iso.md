Al comprar un aceite ves códigos como **15W-40 CK-4 API SN Plus**.
Cada parte de esa etiqueta significa algo específico. Este artículo
enseña a leer las tres clasificaciones principales: **API** (calidad
del aceite), **SAE** (viscosidad), e **ISO** (viscosidad para
hidráulicos).

## API (American Petroleum Institute)

**API** define **niveles de calidad y compatibilidad** del aceite con
distintos motores.

Los aceites API se dividen en dos grupos por tipo de motor:

### Grupo S: motores a gasolina

**S** = Service o Spark ignition (ignición por chispa).

Códigos: SN, SP, SQ (los más modernos).

- **SN** (2010): motores a gasolina 2011+.
- **SP** (2020): motores a gasolina 2020+ con tecnología LSPI
  (Low-Speed Pre-Ignition prevention).
- **SQ** (2024+): última generación.

Las letras van avanzando en el alfabeto — cada categoría nueva es
retrocompatible con las anteriores.

### Grupo C: motores diesel

**C** = Commercial o Compression ignition (ignición por compresión).

Códigos: CJ-4, CK-4, FA-4.

- **CI-4** (2002): motores diesel pre-2007 con EGR pero sin DPF.
  ZDDP alto (1.200 ppm).
- **CJ-4** (2007): motores con **DPF y SCR**. ZDDP reducido a 1.200
  ppm máximo. Detergentes-dispersantes optimizados.
- **CK-4** (2017): mejora sobre CJ-4. Extended drain optimizado. Mejor
  cizalladura y estabilidad.
- **FA-4** (2017): viscosidades más bajas (10W-30, 15W-30) para
  eficiencia de combustible. **Compatible con motores 2017+**
  específicos.

### Cómo elegir la categoría API correcta

**Regla general**: usar la categoría **más moderna** compatible con tu
motor.

- **Motor diesel 2007-2016** con DPF/SCR: usar **CJ-4 o CK-4**.
- **Motor diesel 2017+**: usar **CK-4** o **FA-4** (si el manual lo
  aprueba).
- **Motor diesel pre-2007** (sin DPF): puede usar **CI-4** o superior
  (más moderno también funciona).

**NUNCA** usar categorías más viejas en motores más modernos.
Ejemplo: usar **CI-4 en motor con DPF taponará el DPF** en pocos
meses.

## SAE (Society of Automotive Engineers)

**SAE** define la **viscosidad** del aceite — cuánto fluye a distintas
temperaturas.

### Aceites monogrado

Un solo número. Ejemplos:

- **SAE 30**: viscosidad media, típico climas moderados.
- **SAE 40**: más viscoso, motores con más blow-by.
- **SAE 50**: muy viscoso, motores viejos con desgaste.

Los monogrado son cada vez menos usados — no se comportan bien en
climas variables.

### Aceites multigrado

Dos números separados por "W" (winter). El más común es
**15W-40**.

Formato: `XW-Y`

- **X**: viscosidad en frío (winter).
- **Y**: viscosidad en caliente (a 100°C).

### El número W (frío)

Indica **cuán bien fluye el aceite en frío** — específicamente a
temperaturas bajo cero.

| Grado W | Fluye hasta                   |
| ------- | ----------------------------- |
| 0W      | -40°C                         |
| 5W      | -35°C                         |
| 10W     | -30°C                         |
| 15W     | -25°C                         |
| 20W     | -15°C                         |
| 25W     | -10°C                         |

**Menor número W = mejor comportamiento en frío**.

### El número final (caliente)

Indica la **viscosidad a 100°C** en centistokes.

| Grado | Viscosidad a 100°C (cSt) | Uso típico                    |
| ----- | ------------------------ | ----------------------------- |
| 20    | 5,6-9,3                  | Autos modernos livianos       |
| 30    | 9,3-12,5                 | Autos y motores diesel medios |
| 40    | 12,5-16,3                | Motores diesel pesados        |
| 50    | 16,3-21,9                | Motores muy viejos o carga alta |
| 60    | 21,9-26,1                | Aplicaciones extremas         |

**Mayor número = más viscoso en caliente**.

### Ejemplos comunes en motores diesel

- **15W-40**: el más común en Latam para clima templado.
- **10W-40**: mejor arranque en frío moderado.
- **5W-40 sintético**: climas fríos.
- **10W-30 sintético**: motores modernos con eficiencia de combustible.
- **15W-30**: extended drain moderno (FA-4).

## Elegir la viscosidad correcta

**Depende de**:

1. **Temperatura ambiente** más fría que va a experimentar el motor.
2. **Temperatura de operación** normal.
3. **Tipo y estado del motor**.
4. **Especificación del fabricante**.

**Regla básica**:

- **Clima frío** (-25°C a 20°C): 5W-40 o 10W-40 sintético.
- **Clima templado** (0°C a 35°C): 15W-40 mineral o semi-sintético.
- **Clima cálido** (20°C a 45°C): 15W-40 o 20W-50.

**Motor con mucho desgaste** (blow-by alto): usar viscosidad mayor
(15W-50 o 20W-50) para mejor sellado.

**Motor muy nuevo** con tolerancias finas: seguir especificación
exacta del fabricante — no experimentar.

## ISO (International Organization for Standardization)

**ISO** clasifica los aceites **HIDRÁULICOS** por viscosidad. No se
usa para aceites de motor.

### Grados ISO comunes

| Grado | Viscosidad a 40°C (cSt) | Uso típico                    |
| ----- | ----------------------- | ----------------------------- |
| ISO 22 | 22                     | Climas muy fríos              |
| ISO 32 | 32                     | Climas fríos, baja carga      |
| **ISO 46** | **46**             | **ESTÁNDAR en maquinaria pesada** |
| ISO 68 | 68                     | Clima cálido o carga pesada   |
| ISO 100 | 100                    | Aplicaciones exigentes        |
| ISO 150 | 150                    | Cargas muy altas, baja RPM    |

**El más común** en maquinaria pesada de construcción (excavadoras,
cargadores, bulldozers): **ISO 46**.

### ISO H, HM, HV, HVI

Además del grado numérico, las especificaciones ISO agregan letras:

- **HL**: aceite hidráulico mineral con inhibidores de oxidación y
  corrosión. Uso general.
- **HM**: mineral con aditivos **antidesgaste**. Maquinaria de servicio
  pesado.
- **HV**: mineral con **mejoradores de índice de viscosidad**. Clima
  variable.
- **HVI**: alto índice de viscosidad — muy estable ante temperatura.

**Ejemplo típico** en excavadora: aceite hidráulico **ISO 46 HM** o
**ISO 46 HV**.

## Cómo leer una etiqueta completa

**Ejemplo típico**: Aceite de motor diesel comercial.

```
CATERPILLAR DEO 15W-40 API CJ-4/CI-4 ACEA E9/E7
```

Descifrando:

- **CATERPILLAR DEO**: marca y producto.
- **15W-40**: viscosidad SAE (15W en frío, 40 en caliente).
- **API CJ-4/CI-4**: cumple con categoría API CJ-4 (motores con DPF) y
  CI-4 (motores pre-2007). Retrocompatible.
- **ACEA E9/E7**: cumple con normas europeas ACEA para camiones
  pesados.

Otro ejemplo, para hidráulico:

```
MOBIL DTE 25 ISO 46 HM
```

- **MOBIL DTE 25**: marca y producto.
- **ISO 46**: viscosidad de 46 cSt a 40°C.
- **HM**: mineral con aditivos antidesgaste.

## Otras clasificaciones a conocer

### ACEA (Europa)

Sistema europeo similar a API pero con lógica distinta:

- **A/B**: motores de gasolina y diesel liviano.
- **C**: motores con post-tratamiento (DPF, SCR).
- **E**: motores diesel pesados.

Ejemplos: **ACEA E7** (equivalente a CI-4/CJ-4), **ACEA E9**
(equivalente a CJ-4/CK-4).

### JASO (Japón)

Sistema japonés, principalmente para motos y aplicaciones específicas.

- **JASO MA**: motocicletas 4T con embrague en aceite.
- **JASO MB**: motocicletas 4T con embrague seco.
- **JASO DH-1/DH-2**: motores diesel japoneses.

### Especificaciones de fabricantes

Cada gran fabricante tiene sus propias especificaciones:

- **Caterpillar**: ECF-3, ECF-2 (para sus motores).
- **Cummins**: CES 20081, CES 20086.
- **Volvo**: VDS-3, VDS-4, VDS-4.5.
- **Mercedes**: MB 228.51, MB 228.52.
- **Deutz**: DQC III, DQC IV.

Un buen aceite comercial suele cumplir varias de estas especificaciones
a la vez, listadas en su etiqueta.

## En resumen

Los tres sistemas de clasificación clave:

**API**: calidad y compatibilidad con motores. Grupos S (gasolina) y C
(diesel). Motores diesel modernos requieren CJ-4 o CK-4.

**SAE**: viscosidad del aceite. Multigrados como 15W-40 son estándar
en motores diesel de clima templado. Número W indica frío, número final
indica caliente.

**ISO**: viscosidad de aceites hidráulicos. ISO 46 es el estándar en
maquinaria pesada. NO se usa para aceites de motor.

**Regla de oro**: siempre consultar el manual del fabricante para
saber qué especificación exacta requiere tu motor. Nunca usar
categorías más viejas de las que el motor requiere. Cuando se
mezclan aceites de distintas especificaciones, se pierde la
protección del más moderno.
